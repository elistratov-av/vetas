Действия для запуска выгрузки в ОДОПМ

1. Проверить, что создались таблицы:
odopm.odopm_areas,
odopm.odopm_attributes_specification,
odopm.odopm_catalogs,
odopm.odopm_catalogs_item,
odopm.odopm_districts,
odopm.odopm_organizations,
odopm.organizations_actions,
odopm.references

2. Выполнить первичную выгрузку из одопм в таком порядке:

	./yii odopm/init

   При этом будут обновлены коды бти в таблицах areas, districts

!!! Если в таблице организаций отсутствуют координаты - спарсить их из яндекса ./yii odopm/seed-coordinates - сервис отсекает попытки загрузить
    организацию без координат

4. Проверяем базу на валидные значения. Невыполнение следующих пунктов точно приведет к ошибкам сервиса.

   !!! ВАЖНО. Проверить таблицу контактов на валидные номера телефонов (буквы или слишком много/мало знаков). Убрать или заменить на маски 0000000000.
              Сервис отсекает попытки загрузить организацию, если телефон не соответствует маске

   !!! ВАЖНО. Проверить поля organoizations.schedule. Если будет пустое поле расписания - свалится с ошибкой. Вложенный каталог расписания обязателен (все 7 дней недели).

   !!! ВАЖНО. Тестовая база сейчас не содержит организаций с флагами в reseption_corpses, free_vaccination и pet_registration. Проставить для трех организаций по одному флагу соответственно.
              Для каждой из трех выбранных организаций проставить признак капитального строительства. Т.к это ГВО, то по локиге ОДОПМ они не могут быть не капитальными.
              organizations.capital_structure = TRUE.


5. Выгрузка организаций производится командой ./yii odopm/send {idCatalog}
	Возможные варианты id каталогов:
	- тест
	    5547 - Ветеринарные учреждения
	    5550 - Пункты приема трупов домашних животных
	    5553 - Пункты регистрации домашних животных
	    5554 - Центры бесплатной вакцинации животных против бешенства
	- прод
	    251    - Ветеринарные учреждения
	    100015 - Пункты приема трупов домашних животных
	    102566 - Пункты регистрации домашних животных
	    100039 - Центры бесплатной вакцинации животных против бешенства

    Для полной выгрузки соотв необходимо запустить команду для всех 4 каталогов. Для тестовой достаточно одного

	Для выгрузки всех организаций можно также использовать команду ./yii odopm/send-all


6. Записать команды ./yii odopm/send {idCatalog} в кронтаб (после окончательной отладки сервиса на проде).
   Необходимо также уточнить периодичности обновления.
   В соответствии с ТП_НОД_Ветеринарные учреждения.pdf - ежеквартально (Второй рабочий вторник в первом месяце квартала).
   В соответствии с ТП_НОД_Пункты_приема_трупов_домашних.pdf, ТП_НОД_Пункты_регистрации_домашних.pdf,
   ТП_НОД_Центры_бесплатной_вакцинации.pdf - ежеквартально (Не позднее, чем через 90 дней после последнего обновления)


ВАЖНО!

Тестовый контур ОДОПМ не передает для организаций поля:

ChiefName
ChiefPosition
RespDepartment
PublicServicesAvailable
UNOM
EntryState
EntryAddReason
EntryChangeReason
EntryDeleteReason
ParentEntries
ChildEntries

В связи с этим невозможно на тестовом контуре протестировать правильность их установки!!!
Отладку придется продолжить на проде.

Также на тесте невозможно протестировать удаление организации из-за того, что на тестовом контуре ОДОПМ
в методе getCatalogSpec не возвращает id для поля EntryDeleteReason - в результате получаем ошибку
"Атрибуты, заполняемые при удалении, не прошли проверку".


На тестовом контуре ОДОПМ от прода отличаются не только id каталогов и полей, но и tehName некоторых полей!!!

Например:

Publicphone - PublicPhone
Workinghours - WorkingHours
Dayofweek - DayOfWeek


Поля ParentEntries, ChildEntries имеют тип LINK.
В документации ОДОПМ не описан этот тип поля и принцип его формирования.
